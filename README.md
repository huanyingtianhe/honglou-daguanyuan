# 红楼 · 大观园（Windows 本地版）

基于《红楼梦》的互动剧情游戏，包含电影式插图、人物对白、剧情选择、游园与 3D 跑酷。

## 运行

适用于 Windows 10/11 x64。下载并解压完整仓库，双击 `启动游戏.cmd`，在浏览器打开 http://127.0.0.1:18752/ 。已附带 Node.js，无需另行安装。关闭启动窗口即可停止服务。

## 当前版本

- 63 回主线，第一回 4 张插图，其余每回 3 张，随剧情切换。
- 默认自动推进对白；选择与答题时暂停。
- 透明字幕，人物对白显示小头像，旁白隐藏头像。
- 包含第一回取字、第二回护官符及对白连贯性修订。

## 存档

进度保存在浏览器中，不在仓库里。换设备或浏览器前，在游戏设置中导出存档，再在目标环境导入。

## 目录

- `web/`：已构建的游戏、插图与媒体资源。
- `runtime/`：Windows Node.js 运行环境。
- `server.cjs`：仅监听本机的静态服务器。
- `第三方许可/`：随发行包附带的依赖许可。

这是当前可运行发行目录的版本快照，不包含原始前端开发工程。重复旧版目录、临时工作文件与备份未纳入版本控制。详细说明见 `使用说明.txt`。
